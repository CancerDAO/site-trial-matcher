# 历史 ChiCTR 快照审计（不再作为当前 Demo 数据源）

> 本文只保留旧 2000 项 ChiCTR 索引样本的审计记录。当前运行数据库已经切换到 WHO MCP 2026-08-18 数据与用户提供的 ChiCTR XML，见 `DEMO_REPORT.md`。

## 结论

原来的59项不是Top30机构拥有的试验总量，也不是2000项快照中的全部Top30试验。它是连续三次过滤后的结果：只有Top30机构、已经抓取详情、并且详情文本包含肿瘤标志。

## 完整漏斗

| 层级 | 数量 | 说明 |
|---|---:|---|
| 本地索引记录 | 2000 | 2025年1990项、2026年10项 |

| Top30且详情判为肿瘤 | 59 | 旧Demo最终数量 |

机构名称关联没有造成59项问题：Top30精确名称匹配和去空格/标点后的规范化匹配均为415项。

## 快照边界

- 注册日期范围：2025-12-04至2026-07-05。
- 抓取状态显示2025年索引到第200页、2026年到第2页。
- 详情抓取在2026-07-05遇到ChiCTR HTTP 405防火墙阻断后暂停。
- Top30官网显示的机构累计试验数跨越更长历史范围，例如华西医院4588项，不能与这段2000项时间样本直接比较。

## 当前数据库口径

- 构建器扫描全部2000项索引，但只导入“详情JSON存在且详情判为癌症相关”的200项。
- 200项中Top30机构59项，其他机构141项；Top30只决定合作标签，不决定是否入库。
- 其余712项有详情但不是癌症相关；1088项没有详情。两类均不进入当前匹配数据库。
- `outputs/chictr-snapshot-audit.json`保存逐机构明细，可重复运行 `scripts/audit_chictr_snapshot.py`更新。

要扩大癌症试验库，需要继续抓取更长历史范围并补齐详情，不能把全部912项有详情试验直接当作癌症试验。
